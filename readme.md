## Local Development

### Prerequisites
- Go
- Hugo
- Git

### Run Locally
Clone the repository:

```
git clone https://github.com/ostriandoni/ostriandoni.github.io.git
cd ostriandoni.github.io
hugo server
```

The website will be available at:
```
http://localhost:1313
```

## Deployment
The website is deployed automatically to GitHub Pages using GitHub Actions.

Changes pushed to the configured branch trigger the Hugo build and deployment workflow.

Without further ado, visit [my portfolio](https://ostriandoni.github.io/).
