## Overview
- **Role:** Senior Backend Engineer @ Surface Tribe
- **Company:** Bibit
- **Period:** Jan 2021 – Jan 2025

## Key Contributions
- Developed web services and APIs as a foundation for various functions, including mutual fund transactions, gift card purchases, convenience fees, instant redemption, partner integration, and improving overall system functionality
- Analyzed and translated business/feature requirements into well structured, efficient, and scalable applications, ensuring that the software met the needs of the business and end users
- Collaborated closely with cross functional teams, including Product, Front End, Mobile, and QA teams, to deliver features and improvements that enhance the user experience
- Worked alongside Technical Writers to document existing features that lacked technical documentation by conducting reverse engineering, resulting in comprehensive technical documentation for all features
- Provided advanced technical support (L2 support) to KYC and Customer Experience teams, resolving escalated issues in a timely manner
- Architected transformation and connectivity solutions using third-party APIs, such as Bank Jago, Midtrans (including GoPay and ShopeePay), LinkAja, and OY!
- Optimized existing codes to improve performance and efficiency, ensuring that the apps run smoothly and meet the needs of end users
- Implemented best practices in security and data protection to ensure that the system is secure and that customer data is protected
- Conducted code reviews to ensure adherence to guidelines and coding conventions, maintaining code quality and optimizing system performance
- Mentored new tech hires and junior developers to facilitate knowledge sharing within the team

## Major Project
- Pioneered payment integration with Bank Jago as one of the earliest engineers on the initiative, covering:
  - Payment transactions
  - Recurring transactions
  - Instant redemption
  - Gift card transactions
  - Investment pocket on Bank Jago app
- Implemented convenience fee mechanism across nearly all available payment methods to drive additional revenue
- Migrated legacy LinkAja payment API to LinkAja AppLink integration
- Migrated native Payment API to SNAP BI standard, including:
  - Bank Jago
  - Gopay
  - ShopeePay
- Revamped onboarding flow, including KYC, to reduce drop-off rate
- Developed robo advisory that delivers personalized investment recommendations based on user defined financial goals (e.g., home ownership, education, travel), utilizing LangChain LLM integration
- Implemented automated cash sweep to invest idle funds in the RDN
