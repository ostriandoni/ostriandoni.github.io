## Overview
- **Role:** Software Engineer
- **Company:** Tech Mahindra
- **Period:** Feb 2013 – Jan 2015

## Key Contributions
- Built user authentication and account management for secure subscriber login and account access
- Developed subscriber data services covering balance, quota, and active package retrieval

## Tech Stack
- Java
- Hibernate
- Oracle

## Project Scope & Key Features
- User authentication and account management
- Subscriber information
- Check remaining internet quota, credit balance, validity period, and usage history
- Purchase internet data, call, and SMS packages
- Top up credit or redeem physical Tri vouchers
- Access assistance from the virtual assistant, Triva
