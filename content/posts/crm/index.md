## Overview
- **Role:** Solution Engineer
- **Company:** Hyperscal

## Key Contributions
- Gathered and analyzed business requirements, translating Business User Requirements Documents (BUR/BRD) into Solution Documents (SDD)
- Designed the database schema, including required tables, in accordance with TM Forum guidelines, while ensuring alignment with surrounding systems such as Order Management, Product Catalog, Revenue Management, Work Force Management, and Case Management
- Prepared and provided SQL queries to support and simplify the backend developers implementation process
- Prepared application mockups and prototypes to help the frontend developers easily understand and implement the intended user flow
- Created Test Case Scenarios and conducted System Integration Testing (SIT) to validate end to end functionality across integrated systems
- Support User Acceptance Testing (UAT) with end users and produced UAT documentation
